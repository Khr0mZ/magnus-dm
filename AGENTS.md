# Project workflow

- Work locally and provide a local preview for review.
- Publishing, redeploying, or pushing changes to the hosted Sites repository requires the user's explicit approval of the changes. A request to edit or continue is not publication approval.
- Preserve Magnus Laser's original cyberpunk visual identity from the sibling `cyber-manager` project: Orbitron / Rajdhani typography, saturated neon palette, original logo, glitch and CRT effects. Use the branded city wallpaper; the user explicitly removed Matrix rain.
- The current visual direction is Edgerunners-inspired: category-colored active navigation (lime for the DM desk, cyan for generators, magenta for reference tables, orange for the map), ink-dark surfaces, cyan/magenta signals, hard offset shadows and angular graphic cuts. Active sections must retain their own color rather than all turning acid yellow. Apply it consistently across the whole app through `app/edgerunners.css`, retaining Magnus Laser's orange branding, original fonts/logo and city artwork. Keep glitch brief and interactive, readable text contrast and the shared geometry of both themes.
- Do not use repeated colored left borders or inset strips as decorative accents. Apply category and state colors to surfaces, text and controls when they convey meaning; keep neutral elements free of decorative borders. Retain functional field outlines and keyboard focus.
- Reading mode must keep the same fonts as the dark theme. The M on the city billboard must retain the hollow outline of the dark wallpaper; do not replace it with a solid filled mark.
- The light and dark themes must share layout, spacing, typography, borders, component visibility and effects. Only colors, logo and background artwork may differ; do not add light-only boxes or surfaces.
- Keep UI text at least 14px in both themes and primary reading/input text at 16–18px. Compact the netrunner folders and cards through spacing and grouping, without shrinking text below that minimum.
- Generators and reference tables use horizontal stacks of files with a shared color per category, angular cyberpunk details and extraction effects. Avoid reverting to a generic card grid or a long accordion list of tables.
- The terminal's displayed campaign year is 2080. Prevent accidental text selection in the interface, preserving normal selection in editable fields and explicit copy buttons for results and reference tables.
- Use the orange laser accent from `public/magnus-laser.png`, not red, for Magnus Laser branding. Keep the compact top bar and remove the large introductory hero. The editable session switcher and session actions belong inside the top bar, with a second row only on narrow screens; do not restore a separate session bar above the workspace. Sessions remain browser-local, preserving previously saved data.
- Generator and reference favorites belong to the DM, globally across all sessions. Preserve existing selections during migration. File stacks must visibly overlap and lift the focused/hovered file to the front; use a cyberpunk folder directory for category filters rather than flat tabs.
- Keep category filters compact, without a decorative grid. File stacks use slight edge overlap, with readable titles on touch devices, continuous horizontal scrolling and native swipe; hide the horizontal scrollbar and do not paginate. Mouse clicks must not latch the extraction highlight; preserve visible keyboard focus and stable hover hit areas.
- Favorites use a memory-chip marker with distinct empty and installed states, consistently on generators, reference tables and filters, rather than stars. Preserve the empty circuit; the active state uses a powered angular core and connected traces, without a checkbox tick.
- Keep icons purposeful: remove repeated card pictograms, Generate/row-count card footers, duplicate heading icons and decorative side captions over the wallpaper. Preserve functional controls, category colors and extraction effects; do not add boxes to compensate for unnecessary text.
- Keep the footer removed. Topbar branding uses only the original non-clickable logo, without a duplicated wordmark or subtitle beside it. Adapt navigation, buttons and selectors from cyber-manager's neon, glitch and passing-light effects; dropdown arrows sit beside their values and the theme switch uses Chrome/Flesh.
- Do not restore the standalone dice roller: the game uses Foundry. Keep the yes/no oracle and make open questions use explicit approaches and selectable source tables, with complete labelled results.
- File stacks support mouse dragging as well as native swipe, trackpad and keyboard, without arrow buttons. Dragging must suppress accidental card/favorite clicks. Main sections use distinct terminal, circuit and database icons.
- Rename sessions inline through the editable autocomplete field; Enter or blur saves, Escape cancels, and choosing a suggestion switches sessions without renaming the previous one. Keep the rename button and persistent saved-in-browser label removed. Keep language switch edges fully enclosed.
- Language selection uses two linked translation ports, with its own design rather than a Chrome/Flesh copy. DM tools reuse the actual FileStack/StackFile components, with orange, magenta and green groups and the active workspace below its category. Align form fields, dropdowns and action buttons at 48px control height, without bottom margins on labels in flex form rows.
- Reroll replaces the existing log entry without adding, moving or unpinning it; the result panel reads the same saved entry. Keep one scroll container for the whole session log, without nested entry scrollbars or blocked scroll chaining to the page.
- Keep explorer filters and file hover layers in an isolated stacking context below the result overlay. The session log always sizes to its content, with no minimum height reserved for entries; use only a maximum height to enable scrolling when needed. This applies to empty, single-entry and filtered logs alike.
- Explorer filters have no order selector: always preserve source/catalog order. All card rows stay expanded; their headings are static, without collapse buttons or chevrons. This includes DM tools and favorite stacks.
